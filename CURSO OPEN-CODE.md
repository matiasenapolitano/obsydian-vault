==🟢LLM== --> Es un Large Language Model o modelo de lenguaje de gran tamaño. Basicamente un un sistema de IA entrenado con esteroides (aunque puede responder de forma incorrecta) . Es el motor que utilizan los chatbots como gemini o chatgpt.

- [ ] Escribir y corregir textos
- [ ] Traducir
- [ ] Resumir documentos muy extensos
- [ ] Programar y depurar codigo
- [ ] Responder consultas muy complejas

==🟡TOKENS== --> Puede representar una palabra, parte de una palabram signos de puntuacion o fragmentos de numeros. Ejemplo de [token]

````
[super][mercado][-][$][1][,][250][.][00]
````

Cada LLM tiene una cantidad determinada de capacidad de tokens, cobran segun cada token entrante y saliente y tambien aumenta la latencia segun la cantidad de los mismos.

==🔵VENTANA DE CONTEXTO== --> Es la cantidad maxima de tokens que un LLM puede considerar en cada solicitud, la misma puede incluir prompts, contenido del usuario, historial y demas datos. Es importante diferenciar entre contexto(info disponible) y conocimiento aprendido(patrones incorporados durante el entrenamiento). 
Un prompt puede entrar dentro del campo de texto pero aun asi superar el limite de tokens y hacer equivocarse al LLM.
